# UKM Thrift Mobile Application

A mobile thrift marketplace application developed for UKM students to buy and sell pre-loved items within the university community.

## Technologies Used
- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Realtime Database / Firestore

## Features
- User registration and login
- Upload thrift items
- Browse product listings
- Product categories
- Firebase database integration
- Mobile-friendly UI design

## Project Purpose
This project was developed to provide an easier and more sustainable way for students to trade second-hand items within the UKM community.
